# UNAH · Campus Virtual — Design Handoff v1.4

Contrato del prototipo local actualizado por instrucciones de Joel el 4 de noviembre de 2026. No es una especificación institucional oficial ni una implementación de Moodle.

## Autoridad

Los mockups aprobados gobiernan la composición; las instrucciones posteriores de Joel gobiernan los refinamientos compactos, navegación permanente, recursos, portada de video, acordeones, catálogo y menú contextual. `01-REFERENCIAS/clases.png` es la referencia de Mis cursos. Las tres referencias móviles y `campus-virtual-desktop.jpg` se conservan. `mockup/index.html` es un antecedente, no la autoridad de los tamaños actuales.

`02-DESIGN-SYSTEM/` contiene el mismo sistema original evolucionado a v1.4: documentación y fuente única JSON. `03-ESPECIFICACIONES/` define componentes, responsive, interacciones y aceptación. La copia en el prototipo es idéntica y el JSON genera CSS; no mantener otro Design System ni overrides tipográficos paralelos.

## Alcance

HTML5, CSS modular y JavaScript ES vanilla. Tres cursos de demostración navegables mediante una sola implementación: Administración (65%), Contabilidad I (42%) y Estadística Aplicada (78%). Cuatro unidades y dieciséis clases por curso, materiales y actividades locales. No constituyen contenido oficial.

Navbar permanente en todos los tamaños; sidebar permanente solo desktop. Móvil: navbar de 64px sin línea amarilla, resumen principal informativo, video al ancho interior, menú con curso actual primero y único con progreso/unidades; los demás son enlaces «Ir al curso» del mismo tamaño visual. Acordeones compartidos de 260ms con movimiento reducido y recursos exclusivos.

Mis cursos conserva la composición aprobada, selector de vista y próximas actividades de muestra. La bienvenida utiliza una fotografía auténtica UNAH CC BY-SA 3.0, con original, crédito y derivados WebP conservados en el prototipo. El logo es el SVG oficial suministrado por Joel. Sin Moodle, entregas reales, calificaciones ni publicación.

## Handoff descargable

Contrato vigente v1.4 con utilidad de descarga compartida y reserva inferior para evitar solapamientos. El paquete reúne esta documentación, tokens, CSS implementado, referencias de composición identificadas y licencias. La preparación de GitHub no activa Pages ni autoriza publicación.
